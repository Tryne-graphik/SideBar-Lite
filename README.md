# SideBar (édition simple)

Panneau latéral pour Chrome / Opera : WhatsApp, apps web, notes, Drive.

- **Installer** : télécharger `SideBar-Chrome.zip` (ou `SideBar-Opera.zip`), le décompresser, puis suivre `LISEZ-MOI.txt` (mode développeur → Charger l'extension non empaquetée).
- **Mettre à jour** : copier `MettreAJourSideBar.exe` dans le dossier de l'extension (à côté de `manifest.json`), double-cliquer, puis cliquer sur ⟳ sur la carte SideBar dans `chrome://extensions`.
